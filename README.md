# Анализ даты рождения

Консольная программа запрашивает дату рождения и выводит дату, день недели, високосность года, полный возраст и электронное табло из символов `*`. Ошибочный ввод обрабатывается без трассировки.

## Запуск после клонирования

Требуется Python 3.10 или новее.

```powershell
git clone https://github.com/Aleksei930/birthday-analysis.git
Set-Location birthday-analysis
python birthday.py
```

## Тесты

```powershell
python -m pip install pytest
python -m pytest tests -v
```
